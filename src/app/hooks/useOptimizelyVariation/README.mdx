# useOptimizelyVariation hook

> **Running an experiment? Use the [`<Experiment>`](https://github.com/bbc/simorgh/tree/latest/src/app/components/Experiment) component instead.**
> It calls this hook for you and is the only way to attribute tracking to an experiment. View, click, swipe and custom event trackers rendered inside it are tagged with the experiment in Reverb/Resonance. View, click and swipe trackers also send `<componentName>-views` / `<componentName>-clicks` events to Optimizely; custom event trackers don't, so they can't be used as Optimizely metrics. Experiment details can't be passed to tracking hooks directly.
>
> ```tsx
> <Experiment name="my_flag" type={ExperimentType.SERVER_SIDE}>
>   {variation => (variation === 'variant' ? <NewThing /> : <OldThing />)}
> </Experiment>
> ```
>
> Pass `activate` to defer the decision until, for example, the user scrolls.

The `useOptimizelyVariation` hook handles:

* Decides what variation to show a user via Optimizely
* Automatically updates the variation value if the underlying datafile from Optimizely changes
* Has functionality to override the Optimizely user's attributes
* Uses the `useEffect` hook to prevent issues occuring via server side rendering

`useOptimizelyVariation` must be used in conjunction with the HOC [`withOptimizelyProvider`](https://github.com/bbc/simorgh/tree/latest/src/app/containers/PageHandlers/withOptimizelyProvider) page handler. This is because `useOptimizelyVariation` makes use of features found in the `optimizely` object client that needs to be provided by `withOptimizelyProvider`.
`ExperimentState.CLIENT_SIDE` or  `ExperimentState.SERVER_SIDE` must be specified for the hook to call the respective client side or server side optimizely hooks.

### Usage

Here's an example of its usage:

```jsx
import withOptimizelyProvider from '#containers/PageHandlers/withOptimizelyProvider';
import useOptimizelyVariation from '#hooks/useOptimizelyVariation';

const ExamplePage = () => {
  const variation = useOptimizelyVariation({ experimentName: 'foo-experiment-id', experimentType: ExperimentState.CLIENT_SIDE});

  if (variation === 'variation_1') {
    return <p>I am variation 1</p>;
  } else if (variation === 'variation_2') {
    return <p>I am variation 2</p>;
  }

  return <p>I am not a variation</p>;
};

export default withOptimizelyProvider(ExamplePage);
```
