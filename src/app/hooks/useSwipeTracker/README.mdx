# useSwipeTracker hook

The `useSwipeTracker` hook handles:

- Tracking when a user navigates from one video to another on the
 SMP instance rendered using the Portrait Video Modal.
- Sending the event to Piano via Reverb
- Sending the event to Optimizely (If applicable)

A view event is triggered when:

- A user navigate from one video to another by swiping
- The SMP loads and plays the next video, when 
  - playback ends for the current video, and
  - the config, `autoplay: true`, is set in the SMP config.

`useSwipeTracker` return a function that can be invoked from an event handler. When the parameters necessitating
a view event to be triggered are met, the event handler can then call the function provided by `useSwipeTracker`.

`useSwipeTracker` is primarily intended for use-cases where
- the component you need to track is always in the viewport
- a re-render of the targeted component is not required
- a view event is triggered through an event handler in lieue of
the component coming into view for a stipulted length of time

A view event is also fired to Optimizely using the same mechanism, but only if the underlying props contain an
optimizely object. This method was chosen due to the fact that we don't currently use Optimizely in all of our
page types, and the usage of this hook can be found on some page types which don't have Optimizely, so if we
imported the optimizely object directly in this hook, we would pollute those page type bundles with the
100KB+ of the Optimizely SDK library.

### Props

| Argument          | Type    | Required | Example                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| campaignID        | string  | no       | Provide this to override the \`campaignID\` provided by the \`EventTrackingContext\` component. This is useful for specific campaigns where you want to use a custom campaign ID                                                                                                                                                                                                |
| componentName     | string  | yes      | The name of the component or a url encoded title of a promo e.g. \`most_read\` or \`This%20is%20a%20promo%20title\`                                                                                                                                                                                                                                                             |
| format            | string  | no       | Can be used to track things like the position of a promo e.g. \`[CHD=promo::2]\`                                                                                                                                                                                                                                                                                                |
| url               | string  | no       | The url of the page e.g. https://www.bbc.com/mundo/noticias-america-latina-56989232                                                                                                                                                                                                                                                                                             |
| optimizely        | object  | no       | Need to provide this prop if event tracking is needed for Optimizely, the standard method is to consume the Optimizely context via React's \`useContext\` and imported from the Optimizely SDK \`import { OptimizelyContext } from '@optimizely/react-sdk';\`, the HOC \`withOptimizelyProvider\` needs to be located higher up in the component tree as well for this to work. |
| alwaysInView      | boolean | no       | Use this to track components that are always in view and should not be observed by the IntersectionObserver. This flag is used as an alternative to `eventSent` state variable which is used to track components that require the use of scroll into view.                                                                                                                      |

### Usage

**It's important to note that `useSwipeTracker` logs only 1 view event per invokation.**

With this in mind, here is an example of how you could setup view tracking for a component:

#### Scenario
Log 1 view event when a user swipes on the Portrait Video Modal
to navigate to another video. Refer to the `PortraitVideoModal` component in the example below.

```jsx
/*
 * Example - Log 1 view event when a user swipes to select playback of another video.
 * statsNavigation is the event the SMP fires when a user swipes.
 * statsNavigationCallback is the event handler for the statsNavigation event fired by the SMP.
 * In this example, one view event is triggered when the user swipes on the SMP instance rendered on the page.
 */

const PortraitVideoModal = () => {
  const swipeTracker = useSwipeTracker({
    componentName: 'portrait-video-modal',
    alwaysInView: true,
  });

  const statsNavigationCallback = async (
    e: SMPEvent,
    blocks: PortraitClipMediaBlock[],
    eventTrackingData: EventTrackingData,
    swipeTracker: any,
  ) => {
    const eventTrackingDataForVideoUserSwipedTo = {
      componentName: 'portrait-video-modal',
      alwaysInView: true,
      itemTracker: {
        position: 2
      }
    };

    await swipeTracker(eventTrackingDataForVideoUserSwipedTo);
  };

  return (
    <div>
      <MediaLoader
        css={styles.mediaWrapper}
        blocks={[blocks?.[selectedVideoIndex]]}
        eventMapping={{
          statsNavigation: e =>
            statsNavigationCallback(
              e,
              blocks,
              eventTrackingData,
              swipeTracker,
            ),
      }}
    </div>
  );
};
```
