# Description

Spike-only components that load the UserZoom Site Intercept script on canonical pages. The script is excluded on AMP, Lite and App.

- `UserZoomImmediateIntercept` loads the script when rendered.
- `UserZoomViewIntercept` loads the script when its marker scrolls into view.
- `UserZoomClickIntercept` renders a “Give feedback” button and loads the script when clicked.
