### Description

`PortraitVideoEndScreen` displays a small set of related video links over a portrait media player after playback ends. It is intended for media pages where the existing latest-media links are otherwise below the player on smaller screens.

The component:

- renders up to three video links;
- excludes the current article when an ID is supplied;
- does not autoplay a recommendation;
- provides a mobile-only close control;
- uses the active service's latest-media translation and dark UI theme tokens.
