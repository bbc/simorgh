# Hindi Editorial Picks banner experiment

The client-side Optimizely flag `newswb_ws_hindi_map_save_later_promo` targets
signed-out visitors on Hindi media articles tagged with the Editorial Picks
brand. The matching treatment key shows the existing account banner; all other
decisions show no banner. The flag's traffic allocation is configured in
Optimizely.

The Hindi title and description are provisional translations of the ticket's
English copy; the account action and close labels use existing Hindi
translations. The existing banner's dismissal limits also apply.
